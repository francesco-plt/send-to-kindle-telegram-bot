# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly so it can be fixed before it is disclosed publicly.

- **Preferred:** open a private **GitHub Security Advisory** via **Security → Report a vulnerability** on the repository. This keeps the details confidential while maintainers triage the report.
- **Fallback:** if a Security Advisory cannot be created, open a GitHub Issue describing the problem without including exploit details or sensitive data.

Please include as much relevant information as possible, such as the affected version, a description of the issue, and steps to reproduce. We will acknowledge your report and work to resolve it as quickly as possible.
